---
title: SUD features
---

SUD uses all the [morphosyntactic features of UD](https://universaldependencies.org/u/feat/index.html), ad well as [less standardized UD features](https://universaldependencies.org/misc.html) (which go in MISC column).

The features presented here are more or less standardized features used in SUD treebanks.
Some features, such as [`ExtPos`](./ExtPos), are now used in UD, but have a larger use in SUD.
Features specific to spoken data are introduced [here](guidelines/spoken).
