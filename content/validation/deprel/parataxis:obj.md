# `parataxis:obj` • Deprecated

The depency relation `parataxis:obj` has been deleted. 
Direct discourse is now attached its governor by the relation [`comp:obj`](guidelines/universal/deprel/comp/comp:obj) with the features `Reported=Yes`.
See [Reported Speech](guidelines/universal/construction/reported_speech).
