# SUD Documentation

This website is a new version (2026, still under construction) of the SUD guidelines.

The doc contain three parts:
 - SUD Guidelines: these pages describe tags used in the SUD annotation scheme, as well as the annotation of main constructions.
 - SUD Validation: contains the rules of the SUD validator. These pages are linked to the guidelines: constraints on the use of a given tag produce validation rules
 - Help pages: propose templates.
